APKM / APKG

v0.5.0 · Android APK manager

从可信软件源下载 APK，通过已授权 ADB 或安卓宿主 root 安装。APKM 是源客户端，APKG 是安装后端；与 .apkm 容器格式无关，也不管理 Arch 的 pkg 软件包。

0.5.0 · APKM / APKS / XAPK

支持单套基础 APK＋拆分包，ADB / 安卓 root 均可安装；OBB 跳过并提示。bundletool 多变体 APKS 可使用 --bundletool JAR 适配器（需另装 Java），universal APKS 可用。

apkg install ./application.apkm
apkg --mode root install ./application.xapk

Command guide · 四步实施 / Feasibility review

使用与当前功能

apkm source add fdroid https://f-droid.org/repo --type fdroid
apkm search termux
apkm info com.termux
apkm install com.termux
apkm update fdroid
apkm remove com.example.app
LANG=C apkm --help
man apkm

搜索、详情和安装读取已验证的本地索引；仅添加源、切换镜像或 update 时下载索引。安装成功并确认版本后自动删除 APK；--keep-apk 可保留。

0.5.0：apkm remove 委托 apkg，校验包名、去重、跳过未安装应用并确认卸载结果。卸载通常删除应用数据，需要交互确认或--yes。help 按语言环境显示中英文，man 为英文；运行日志仍主要是中文。

Termux 已配置本项目软件源后可这样升级：

apt update
apt install --no-install-recommends apkm
