usage: apkg [-h] [--version] [--mode {auto,adb,root}] [--serial SERIAL]
            [--json] [--no-progress] [--yes]
            {install,info,list,remove,doctor} ...

Local Android APK installation backend

positional arguments:
  {install,info,list,remove,doctor}
    install             Install local APKs
    info                Inspect an installed Android application
    list                List applications on the device
    remove              Uninstall Android applications and their data
    doctor              Check device, permissions and environment

options:
  -h, --help            show this help message and exit
  --version             show program's version number and exit
  --mode {auto,adb,root}
                        Backend; auto prefers ADB, then checks Android host
                        root
  --serial SERIAL       ADB serial; required with multiple devices
  --json                Emit newline-delimited JSON events
  --no-progress         Show stage messages only
  --yes                 Skip uninstall confirmation, not Android authorization
