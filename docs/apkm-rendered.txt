[1mNAME[0m
       apkm - signed Android APK repository client

[1mSYNOPSIS[0m
       [1mapkm [22m[global-options] command [arguments]

[1mDESCRIPTION[0m
       Download  verified APK files from configured HTTPS repositories and in‐
       voke apkg to install them on an authorized Android target.

[1mCOMMANDS[0m
       [1msource add NAME URL --keyring PATH[0m
              Verify and add a repository using a  previously  trusted  binary
              GPG keyring.

       [1msource add NAME URL --type fdroid [--keyring PATH][0m
              Add   a  GPG-signed  F-Droid  v1  repository.  The  official  f-
              droid.org/repo uses the bundled official key; other repositories
              require --keyring.  Stable variants are selected by Android  API
              and ABI.

       [1msource list | source remove NAME[0m
              List or remove configured repositories.

       [1mupdate [SOURCE ...][0m
              Download and verify signed indexes; omit sources to refresh all.
              Search,  info, install and upgrade use the local verified cache.
              Legacy 0.2.0 caches are reused; missing caches require update.

       [1msource set-url NAME URL[0m
              Verify a mirror index using the existing trusted key  and  roll‐
              back  checks,  then  replace  the source URL while retaining the
              source name.

       [1msearch KEYWORD | info NAME[0m
              Search or inspect repository applications.

       [1minstall [--download-only] [--output-dir PATH] NAME ...[0m
              Download, verify and optionally install single APK files.

       [1mupgrade [NAME ...][0m
              Upgrade installed  applications  recognized  by  the  configured
              repositories.

       [1mlist | doctor[0m
              List Android applications or diagnose the backend.

       [1mremove PACKAGE-ID ...[0m
              Uninstall  after  confirmation.  Package IDs are Android package
              names.

[1mGLOBAL OPTIONS[0m
       Place global options before the command.

       [1m--mode auto|adb|root[0m
              Prefer authorized ADB in auto mode; otherwise verify  local  An‐
              droid host root.

       [1m--serial SERIAL[0m
              Select  an  ADB  device. Required when multiple devices are con‐
              nected.

       [1m--json [22mEmit newline-delimited JSON events.

       [1m--no-progress[0m
              Disable intermediate download progress events.

       [1m--yes  [22mSkip uninstall confirmation, not Android authorization.

       [1m--version | --help[0m
              Show version or help. Subcommands accept --help.

[1mFILES[0m
       [4m$XDG_CONFIG_HOME/apkm/sources.json[24m or ~/.config/apkm/sources.json  con‐
       tains repository URLs and trusted keyring paths.

       [4m$XDG_CACHE_HOME/apkm/apks/[24m or ~/.cache/apkm/apks/ stores verified down‐
       loads.

[1mSECURITY[0m
       Repository  signatures and APK hashes are verified before installation.
       Do not trust a public key solely because it arrived from the  same  un‐
       trusted site.  APK update signing compatibility is enforced by Android.
       Linux  root and PRoot simulated root do not imply Android host root ac‐
       cess.

[1mPROGRESS[0m
       Download events contain actual byte counts. Android installation gener‐
       ally provides status and completion rather than continuous percentages.

[1mEXIT STATUS[0m
       0 success; 1 general or partial failure; 2 invalid usage/configuration;
       3 backend/authorization failure; 4 integrity/index failure;  5  Android
       operation  failure;  130  interrupted. Network or filesystem exceptions
       may return 1.
